# 秦直道远征录

> 循两千年前的帝国驰道北上，把八百公里秦直道串成一条可亲自丈量的历史轴线。

一个纯静态前端项目，包含 **10 日自驾行程规划** 与 **RPG 任务公会** 两个页面，用于记录和 gamify 一次从关中到河套的秦直道自驾远征。

## 在线访问

https://githubcucu.github.io/qin-zhidao-expedition/

## 功能

**十日行程**（`itinerary.js`）

- 10 天完整路书：日期、路线、里程、强度、当日点位与实用提示
- 路线节点图：西安 → 庆阳 → 延安 → 榆林 → 鄂尔多斯 → 包头
- 按主题筛选日程：遗址 / 徒步 / 石窟 / 自然 / 草原 / 边塞
- 完成打卡，盖下电子路印（进度保存在 `localStorage`）
- 出发前六项准备清单，勾选状态本地留存

**任务公会**（`rpg.js`）

- 悬赏任务板：探索 / 徒步 / 考古 / 摄影 / 协作五类任务
- 难度分级（普通 / 稀有 / 史诗 / 传说）与 XP 奖励、队伍席位进度
- 任务搜索与类型筛选
- 发布自定义任务，钤印上板
- 公会守则：文保优先、无痕探索

## 本地预览

项目使用原生 ES Module，**必须通过 HTTP 打开**，直接双击 `index.html`（`file://`）会被浏览器的 CORS 策略拦截。

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

也可以用其他静态服务器，例如 `npx serve .`。

## 技术栈

无构建、无依赖、`package.json` 为零：

- 原生 JavaScript ES Module（无框架）
- Tailwind CSS（CDN，Play CDN 版本）
- Remix Icon 图标（CDN）
- Google Fonts 思源宋体

> Play CDN 仅适合原型与演示，若用于生产环境建议改为本地构建 Tailwind。

## 项目结构

```
.
├── index.html      # 单页入口，含布局与顶部导航
├── main.js         # 路由与页面切换（hash 路由）
├── itinerary.js    # 十日行程数据、渲染与交互
├── rpg.js          # 任务公会数据、渲染与交互
└── .gitignore
```

## 数据存储

所有进度（日程完成、准备清单、自定义任务）保存在浏览器 `localStorage` 中，键名前缀为 `qin-`。不依赖后端，清除浏览器数据会一并清空。

## 安全提示

部分秦直道遗址位于未铺装道路附近，雨后黄土路面湿滑。请勿驶入文保范围或无明确通行标识的便道，不攀爬、不刻画、不捡拾任何遗址构件。
